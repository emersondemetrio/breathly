# breathly

A simple breath pacing app to help you relax and focus. Inhale for N seconds, exhale for 2N seconds. Perfect for breathwork, meditation, and mindfulness practice.

## Features

- Customizable breath timing
- Visual and audio guidance
- Clean, minimalist interface
- Perfect for daily meditation practice

## Tech Stack

- [Next.js](https://nextjs.org)
- [React](https://reactjs.org)
- [Tailwind CSS](https://tailwindcss.com)
- [TypeScript](https://www.typescriptlang.org)

## Getting Started

1. Clone the repository
2. Install dependencies with `yarn install`
3. Run the development server with `yarn dev`
4. Open [http://localhost:3000](http://localhost:3000) in your browser
